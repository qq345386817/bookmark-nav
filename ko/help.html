Bookmark Nav 도움말

Bookmark Nav 설치, 북마크 권한, 빠른 검색, Chrome 기본 새 탭으로 되돌리는 방법을 안내합니다.

시작하기

  • Chrome 웹 스토어에서 Bookmark Nav를 설치합니다.
  • Chrome이 요청하면 북마크 권한을 승인합니다.
  • 새 탭을 열어 북마크 대시보드를 확인합니다.
  • 검색창에 입력해 제목, URL 또는 폴더 경로로 필터링합니다.

왜 북마크 권한이 필요한가요?

기존 폴더와 저장된 링크를 표시하려면 Chrome bookmarks API가 필요합니다. Bookmark Nav는 이 데이터를 Chrome 안에서 로컬로 읽으며 업로드하지 않습니다.

검색 방식

검색은 북마크 제목, URL, 폴더 경로를 대상으로 합니다. 페이지 제목이 기억나지 않아도 폴더를 기억하면 더 쉽게 찾을 수 있습니다.

최근 추가 및 모든 북마크

최근 추가는 새로 저장한 링크를 보여줍니다. 모든 북마크는 모든 폴더를 아우르는 검색 보기를 제공합니다.

Chrome 기본 새 탭 복원

chrome://extensions를 열고 Bookmark Nav를 찾아 비활성화하거나 제거하세요. Chrome이 기본 새 탭 동작으로 돌아갑니다.
