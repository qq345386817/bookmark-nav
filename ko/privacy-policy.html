요약

Bookmark Nav는 북마크나 개인정보를 수집, 업로드, 판매, 대여, 이전 또는 공유하지 않습니다. 북마크 데이터는 브라우저 안에 남습니다.

수집하지 않는 정보

Bookmark Nav는 계정이 필요하지 않으며 이름, 이메일 주소, 방문 기록, 키 입력, 북마크 내용 또는 기타 개인정보를 수집하지 않습니다.

북마크 데이터

확장 프로그램은 Chrome bookmarks API로 북마크를 표시하고 검색하며 사용자가 선택한 편집, 이동, 삭제 및 가져오기를 수행합니다. 데이터는 Chrome에서 로컬로 처리되며 당사나 제3자 서버로 전송되지 않습니다.

로컬 확장 프로그램 설정

테마, 보기, 펼친 폴더 및 사용 횟수는 Chrome 확장 프로그램의 로컬 저장소에 저장하며 동기화 저장소는 사용하지 않습니다. 실행 취소 확인을 위해 최근 가져오기 상태, 새 폴더 ID 및 콘텐츠 지문도 로컬에 저장합니다. 입력 HTML과 북마크 내용은 저장하지 않습니다.

로컬 파일 처리

사이트와 확장 프로그램 병합 도구는 선택한 HTML을 현재 탭 메모리에서 처리하며 업로드하거나 분석에 사용하지 않습니다. 새로고침하거나 페이지를 떠나면 지워집니다. 다운로드한 HTML 백업과 보고서는 기기에 저장됩니다. Chrome은 브라우저 설정에 따라 추가된 북마크를 동기화할 수 있습니다. 설치 링크의 고정 캠페인 태그에는 파일명이나 북마크 URL이 포함되지 않습니다.

분석 및 추적

Bookmark Nav는 확장 프로그램 안에서 Google Analytics 또는 기타 분석 추적기를 사용하지 않습니다. 북마크 사용 방식을 추적하지 않습니다.

쿠키

Bookmark Nav 확장 프로그램은 쿠키를 사용하지 않습니다. 이 정적 웹사이트의 핵심 페이지도 쿠키가 필요하지 않습니다.

아동 개인정보

Bookmark Nav는 일반 생산성 도구이며 아동의 개인정보를 고의로 수집하지 않습니다.

정책 변경

확장 프로그램이 변경되면 이 개인정보처리방침을 업데이트할 수 있습니다. 중요한 변경이 있을 때는 페이지 상단의 시행일을 업데이트합니다.

가져오기 기록 보관
