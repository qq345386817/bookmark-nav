Bookmark Nav Aide

Ce guide explique l installation, l autorisation des favoris, la recherche et le retour au nouvel onglet Chrome par defaut.

Demarrage

  • Installez Bookmark Nav depuis le Chrome Web Store.
  • Acceptez l autorisation des favoris lorsque Chrome la demande.
  • Ouvrez un nouvel onglet pour voir le tableau de bord des favoris.
  • Tapez dans le champ de recherche pour filtrer par titre, URL ou dossier.

Pourquoi l autorisation des favoris est-elle necessaire ?

L extension utilise l API bookmarks de Chrome pour afficher vos dossiers et liens enregistres. Bookmark Nav lit ces donnees localement dans Chrome et ne les envoie pas.

Fonctionnement de la recherche

La recherche correspond aux titres, URL et chemins de dossiers. Vous pouvez retrouver un lien meme si vous vous souvenez surtout du dossier.

Ajoutes recemment et tous les favoris

Ajoutes recemment affiche vos derniers liens enregistres. Tous les favoris offre une vue de recherche plate sur tous les dossiers.

Restaurer le nouvel onglet Chrome par defaut

Ouvrez chrome://extensions, trouvez Bookmark Nav, puis desactivez ou supprimez l extension. Chrome revient au comportement par defaut.
