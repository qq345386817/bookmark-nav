Bookmark Nav Help

Use this guide to install Bookmark Nav, understand the bookmarks permission, search faster, and restore Chrome's default new tab page if needed.

Getting Started

  • Install Bookmark Nav from the Chrome Web Store.
  • Approve the bookmarks permission when Chrome asks for it.
  • Open a new tab to see your bookmark dashboard.
  • Type in the search field to filter by title, URL, or folder path.

Why does Bookmark Nav need bookmark permission?

The extension needs Chrome's bookmarks API to display your existing folders and saved links. Bookmark Nav reads that data locally inside Chrome and does not upload it.

How search works

Search matches bookmark titles, URLs, and folder paths. This makes it easier to find vague bookmarks when you remember the folder but not the exact page title.

Recently Added and All Bookmarks

Recently Added shows a short list of your newest saved links. All Bookmarks gives you a flat searchable view across every bookmark folder.

Restore Chrome's default new tab page

Open chrome://extensions, find Bookmark Nav, then disable or remove the extension. Chrome will return to its default new tab behavior.
