Local bookmark manager

Manage Chrome bookmarks without moving them to another service.

Bookmark Nav keeps Chrome bookmarks as the source of truth, then adds a faster local workspace for search, folders, cleanup, and daily access.

Install from Chrome Web StorePrivacy approach

What local means here

Bookmark Nav reads and updates the bookmarks already stored in Chrome. It does not ask you to create an account, import links into a remote dashboard, or rebuild your folder structure somewhere else.

Local workflows it improves

  • Search bookmark titles, URLs, and folder paths from a new tab.
  • Browse existing Chrome bookmark folders from a persistent sidebar.
  • Add, rename, move, delete, reorder, and batch-move bookmark cards.
  • Review duplicate URLs, empty folders, and unsorted top-level bookmarks.
  • Export a Markdown cleanup report before reorganizing a large collection.

Where it fits

Use Bookmark Nav when your link collection already lives in Chrome and you want a better daily interface for it. If you need team sharing, cloud collections, or cross-browser sync outside Chrome, a dedicated cloud bookmark service may be a better fit.
