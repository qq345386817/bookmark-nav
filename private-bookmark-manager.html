Private bookmark manager

Your bookmarks should stay in your browser.

Bookmark Nav is designed for people who want better bookmark access without moving their link collection into another account or cloud service.

Install from Chrome Web StoreRead Privacy Policy

Local-first by design

Bookmark Nav uses Chrome's bookmarks API to display the folders and links already stored in your browser. Preferences such as theme and expanded folders are stored in local extension storage.

No account migration

You do not need to import bookmarks into a third-party service, create a new account, or rebuild folder structure. Bookmark Nav uses Chrome bookmarks as the source of truth.

Clear limits

Bookmark Nav does not provide cloud backup, team sharing, analytics, or AI processing. That is intentional: the product is focused on fast local access and practical cleanup.
