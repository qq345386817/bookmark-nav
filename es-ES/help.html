Bookmark Nav Ayuda

Esta guia explica la instalacion, el permiso de marcadores, la busqueda y como volver a la nueva pestana predeterminada de Chrome.

Primeros pasos

  • Instala Bookmark Nav desde Chrome Web Store.
  • Acepta el permiso de marcadores cuando Chrome lo solicite.
  • Abre una nueva pestana para ver tu panel de marcadores.
  • Escribe en el buscador para filtrar por titulo, URL o ruta de carpeta.

Por que necesita permiso de marcadores?

La extension usa la API de marcadores de Chrome para mostrar tus carpetas y enlaces guardados. Bookmark Nav lee esos datos localmente en Chrome y no los sube.

Como funciona la busqueda

La busqueda coincide con titulos, URLs y rutas de carpetas. Asi puedes encontrar enlaces aunque recuerdes mejor la carpeta que el titulo exacto.

Anadidos recientemente y todos los marcadores

Anadidos recientemente muestra tus enlaces guardados mas nuevos. Todos los marcadores ofrece una vista plana de busqueda en todas las carpetas.

Restaurar la nueva pestana predeterminada de Chrome

Abre chrome://extensions, busca Bookmark Nav y desactiva o elimina la extension. Chrome volvera a su comportamiento predeterminado.

Combinar archivos de marcadores

Selecciona dos HTML exportados de Chrome, revisa duplicados, descarga el archivo combinado e impórtalo en Chrome. Combina archivos exportados, no cuentas ni sincronización del navegador.

Web frente a importación en la extensión

El sitio funciona sin extensión y solo descarga HTML. La adición directa, copia y deshacer verificado están preparados para la extensión 1.3.1; no asumas que ya están en la versión pública. Comprueba la versión instalada y el menú de importación. La adición directa crea una carpeta separada y usa fechas actuales, no las originales del HTML.
