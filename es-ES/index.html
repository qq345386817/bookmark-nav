Funciones

Un inicio mas claro para tus enlaces guardados.

New tab dashboard

Replace Chrome's default new tab page with a bookmark workspace built from your existing folders.

Instant search

Search bookmark titles, URLs, and folder paths without opening Chrome's bookmark manager.

Folder navigation

Browse folders from a persistent sidebar, then jump back to recently added links or all bookmarks.

Local-first privacy

Your bookmark data stays in Chrome. Bookmark Nav does not collect, upload, sell, or transfer it.
