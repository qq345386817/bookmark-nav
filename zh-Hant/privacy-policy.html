Bookmark Nav 隱私權政策

2026-10-09

摘要

Bookmark Nav 不收集、上傳、出售、出租、转移或共享你的書籤或个人資訊。你的書籤数据保留在瀏覽器中。

我们不收集的資訊

Bookmark Nav 不需要账户，也不收集你的姓名、邮箱、浏览历史、按键、書籤内容或其他个人資訊。

書籤数据

擴充功能使用 Chrome 書籤 API 顯示和搜尋書籤，並執行你選擇的編輯、移動、刪除和匯入操作。資料僅在 Chrome 本機處理，不會傳送給我們或第三方伺服器。

本地扩展设置

主題、所選檢視、展開的資料夾及本機使用計數儲存在 Chrome 擴充功能的本機儲存空間，不使用同步儲存空間。最近一次匯入狀態、新資料夾 ID 與內容指紋亦僅儲存在本機，用於驗證後復原。匯入 HTML 與書籤內容不會儲存在擴充功能儲存空間。

本機檔案處理

網站與擴充功能合併工具僅在目前分頁的記憶體中讀取所選 HTML 檔案，不上傳、不用於分析；重新整理或離開即清除。下載的 HTML 備份和報告留在你的裝置。Chrome 可能依瀏覽器設定同步新增書籤。安裝連結僅使用固定推廣標記，不包含檔名或書籤網址。

分析和跟踪

Bookmark Nav 擴充功能内不使用 Google Analytics 或其他分析跟踪器。我们不会跟踪你如何使用書籤。

Cookie

Bookmark Nav 擴充功能不使用 Cookie。这个静态网站的核心页面也不需要 Cookie。

儿童隱私

Bookmark Nav 是通用效率工具，不会有意收集儿童个人資訊。

政策变更

当擴充功能功能变化时，我们可能更新本隱私政策。发生重大变更时，页面顶部的生效日期会同步更新。

联系方式

如有隱私政策相关问题，请发送邮件至 cameoshell09@gmail.com。

有限使用

Bookmark Nav 遵守 Chrome Web Store 使用者資料政策及其有限使用要求。書籤存取僅用於此處描述的使用者功能，不用於廣告、使用者分析、出售或無關的資料轉移。 Chrome Web Store Limited Use

匯入記錄保留

後續匯入會取代最近一次本機匯入記錄，解除安裝擴充功能會移除該記錄。關閉工具會清除所選檔案，但不一定會停止已在擴充功能背景啟動的匯入。
