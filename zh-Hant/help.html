Bookmark Nav 說明

了解如何安裝 Bookmark Nav、授權書籤權限、快速搜尋，以及恢復 Chrome 預設新分頁。

入門

  • 從 Chrome 線上應用程式商店安裝 Bookmark Nav。
  • 當 Chrome 要求時，同意書籤權限。
  • 開啟新分頁查看書籤儀表板。
  • 在搜尋框輸入內容，依標題、URL 或資料夾路徑篩選。

為什麼需要書籤權限？

擴充功能需要 Chrome 書籤 API 來顯示你已有的資料夾和連結。Bookmark Nav 只在 Chrome 本機讀取這些資料，不會上傳。

搜尋如何運作？

搜尋會比對書籤標題、URL 和資料夾路徑。即使記不清頁面標題，只記得資料夾，也能更快定位。

最近新增和全部書籤

最近新增會顯示最新儲存的連結。全部書籤提供跨所有資料夾的扁平搜尋視圖。

恢復 Chrome 預設新分頁

開啟 chrome://extensions，找到 Bookmark Nav，然後停用或移除擴充功能。Chrome 會恢復預設新分頁。
