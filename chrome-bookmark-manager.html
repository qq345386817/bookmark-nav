Chrome bookmark manager

A faster way to use Chrome bookmarks.

Chrome's built-in bookmark manager is fine for occasional edits. Bookmark Nav is built for daily access: search, browse, organize, and open saved links from your new tab page.

Install from Chrome Web StoreRead Help

Why use a bookmark manager extension?

Large bookmark collections become hard to scan from Chrome menus. Bookmark Nav keeps your existing Chrome bookmark tree, but presents it as a focused dashboard with search, folder context, recent links, and cleanup views.

What Bookmark Nav adds

  • Search bookmark titles, URLs, and folder paths.
  • Browse folders from a persistent sidebar.
  • Add, rename, move, delete, and reorder bookmark cards.
  • Find duplicate bookmarks and empty folders.
  • Export a Markdown cleanup report before reorganizing.

What it does not do

Bookmark Nav is not a cloud bookmark service. It does not require an account, does not replace Chrome sync, and does not upload your bookmark data.
