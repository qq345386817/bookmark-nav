Bookmark Nav Privacy Policy

2026-10-09

Summary

Bookmark Nav does not collect, upload, sell, rent, transfer, or share your bookmarks or personal information. Your bookmark data stays in your browser.

Information We Do Not Collect

Bookmark Nav does not require an account and does not collect your name, email address, browsing history, keystrokes, bookmark contents, or other personal information.

Bookmark Data

The extension uses Chrome's bookmarks API to display and search bookmarks and to perform edits, moves, deletions and imports that you choose. Processing stays in Chrome; bookmark data is not sent to us or a third-party server.

Local Extension Settings

Theme, selected view, expanded folders and local usage counters are stored in Chrome extension local storage, not synced extension storage. The latest import status, new folder ID and content fingerprint are also kept locally for guarded undo. Imported HTML and bookmark contents are not saved in extension storage.

Local File Processing

The website and extension merge tool read selected HTML files into memory in the current tab. Files are not uploaded or used for analytics; leaving or refreshing clears them. Downloaded HTML backups and reports stay on your device. Chrome may sync bookmarks you add according to your browser settings. Extension install links use fixed campaign tags, never file names or bookmark URLs.

Analytics and Tracking

Bookmark Nav does not use Google Analytics or any other analytics tracker in the extension. We do not track how you use your bookmarks.

Cookies

The Bookmark Nav extension does not use cookies. This static website does not require cookies for its core pages.

Children's Privacy

Bookmark Nav is a general productivity tool and does not knowingly collect personal information from children.

Changes to This Policy

We may update this Privacy Policy when the extension changes. The effective date at the top of this page will be updated when we make material changes.

Contact

If you have questions about this Privacy Policy, contact us at cameoshell09@gmail.com.

Limited Use

Bookmark Nav complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Bookmark access is used only for the user-facing features described here, not advertising, profiling, sale or unrelated transfers. Chrome Web Store Limited Use

Import retention

The latest local import record is replaced by a later import or removed when the extension is uninstalled. Closing the tool clears its selected files but does not necessarily stop an import already started in the extension background.
