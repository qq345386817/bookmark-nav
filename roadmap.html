Roadmap

A focused bookmark workspace for Chrome.

Bookmark Nav will stay centered on fast local bookmark access, practical cleanup, and low-friction organization. It is not trying to become another cloud bookmark account.

Install from Chrome Web StoreView Changelog

Now

  • New tab bookmark dashboard.
  • Search by title, URL, and folder path.
  • Folder browsing, recent links, cleanup views, and bulk actions.
  • Local preferences for theme, expanded folders, and last view.

Next

  • Improve screenshot and store listing experiments based on install conversion.
  • Add more comparison and workflow guides for people searching for better bookmark tools.
  • Refine cleanup workflows so large bookmark collections are easier to reorganize safely.
  • Collect ratings only after real usage, without interrupting first-time setup.

Not Planned

  • Accounts or mandatory cloud sync.
  • Uploading bookmark contents for analytics.
  • Team bookmark sharing before there is clear user demand.
  • AI bookmark processing before core usage is proven.
