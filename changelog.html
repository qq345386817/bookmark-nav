Changelog

What is new in Bookmark Nav.

Bookmark Nav is being rebuilt around a simple idea: make the bookmarks already in Chrome easier to search, open, and clean up from every new tab.

Install from Chrome Web StoreView Roadmap

Website: eight-language bookmark HTML merger

2026-10-09: the standalone bookmark merger is live in eight languages. Merge two local exports, review exact-URL duplicates and download HTML without installing an extension. Read the export, merge and import guide.

Chrome extension 1.3.1: prepared release candidate

The prepared build adds the localized import tool, backup, additive import into a new folder and guarded undo. This website update does not publish the Chrome extension. Check the Chrome Web Store listing and your installed version for availability; the website tool can be used now.

Version 1.2.0

Major new tab dashboard update.

  • Added a searchable Chrome bookmark dashboard for every new tab.
  • Added folder browsing, recently added links, and all-bookmarks search.
  • Added add, rename, move, delete, reorder, and bulk bookmark actions.
  • Added cleanup views for inbox bookmarks, duplicate URLs, and empty folders.
  • Added Markdown cleanup report export.
  • Added light/dark theme preferences and local state persistence.
  • Expanded Chrome Web Store metadata and website localization.

Version 1.0

Initial Chrome Web Store release with a basic bookmark navigation experience.

Release Notes

Bookmark Nav stays local-first. The extension uses Chrome bookmarks as the source of truth and does not require an account or a cloud bookmark service. The website merger processes exported files locally; it does not merge Chrome accounts or replace Chrome sync.
