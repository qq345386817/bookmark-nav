Bookmark new tab

Make every new tab useful.

Bookmark Nav replaces the blank new tab moment with the links you already saved: daily tools, project docs, research, dashboards, and recently added pages.

Install from Chrome Web StoreCompare with Chrome's manager

Built for the first few seconds of a new tab

A new tab should help you get somewhere. Bookmark Nav puts search first, keeps folders close, and shows recently added links so saved pages are not forgotten.

Daily workflows

  • Start work by opening project docs, GitHub, dashboards, and admin pages.
  • Find research links by title, URL, or folder path.
  • Move unsorted top-level bookmarks into better folders.
  • Switch to dark mode for low-light browsing.

Private by default

The extension reads Chrome bookmarks locally and stores UI preferences locally. It does not collect, upload, sell, or transfer your bookmark data.
