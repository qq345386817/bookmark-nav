Bookmark dashboard

A dashboard for saved links.

Bookmarks are most useful when they are visible, searchable, and easy to scan. Bookmark Nav turns Chrome bookmarks into a practical dashboard.

Install from Chrome Web StoreNew tab workflow

What the dashboard shows

  • Top-level bookmark folders.
  • Recent bookmarks for quick continuation.
  • All bookmarks with title, domain, and folder path.
  • Cleanup views for duplicates, empty folders, and unsorted top-level links.

Organization without setup

The dashboard uses your existing Chrome folders. You can add, rename, move, delete, reorder, and batch-move bookmarks without leaving the new tab workspace.

Useful for recurring work

Bookmark Nav is especially useful for developers, researchers, designers, operators, and anyone who opens the same saved tools and documents throughout the day.
