Bookmark Nav プライバシーポリシー

2026-10-09

概要

Bookmark Nav はブックマークや個人情報を収集、アップロード、販売、貸与、転送、共有しません。ブックマークデータはブラウザ内に残ります。

収集しない情報

Bookmark Nav はアカウントを必要とせず、氏名、メールアドレス、閲覧履歴、キー入力、ブックマーク内容、その他の個人情報を収集しません。

ブックマークデータ

拡張機能は Chrome bookmarks API でブックマークを表示・検索し、選択した編集、移動、削除、インポートを実行します。処理は Chrome 内で行い、データを当方や第三者サーバーに送信しません。

ローカル拡張機能設定

テーマ、ビュー、展開フォルダ、利用回数は Chrome 拡張機能のローカルストレージに保存し、同期ストレージは使用しません。取り消し確認用に最新のインポート状態、新規フォルダ ID、内容の指紋も保存します。入力 HTML やブックマーク内容は保存しません。

ローカルファイル処理

サイトと拡張機能の結合ツールは選択した HTML を現在のタブのメモリで処理し、アップロードや分析に使用しません。更新・移動で消去されます。HTML バックアップとレポートのダウンロードは端末に保存されます。Chrome は設定により追加したブックマークを同期する場合があります。インストールリンクの固定キャンペーンタグにファイル名やブックマーク URL は含みません。

分析とトラッキング

Bookmark Nav は拡張機能内で Google Analytics などの分析トラッカーを使用しません。ブックマークの使い方を追跡しません。

Cookie

Bookmark Nav 拡張機能は Cookie を使用しません。この静的サイトの基本ページにも Cookie は不要です。

子どものプライバシー

Bookmark Nav は一般向けの生産性ツールであり、子どもの個人情報を意図的に収集しません。

ポリシーの変更

拡張機能の変更に応じて、このプライバシーポリシーを更新する場合があります。重要な変更がある場合は、ページ上部の発効日を更新します。

限定的な使用

Bookmark Nav は Chrome Web Store のユーザーデータポリシーと限定的な使用の要件を遵守します。ブックマークへのアクセスは記載されたユーザー向け機能にのみ使用し、広告、プロファイリング、販売、無関係な転送には使用しません。 Chrome Web Store Limited Use

インポート記録の保持

最新のローカル記録は次のインポートで置き換えられ、拡張機能のアンインストール時に削除されます。ツールを閉じると選択したファイルは消去されますが、バックグラウンドで開始済みのインポートが停止するとは限りません。
