Bookmark Nav プライバシーポリシー

発効日: 2026年5月19日

概要

Bookmark Nav はブックマークや個人情報を収集、アップロード、販売、貸与、転送、共有しません。ブックマークデータはブラウザ内に残ります。

収集しない情報

Bookmark Nav はアカウントを必要とせず、氏名、メールアドレス、閲覧履歴、キー入力、ブックマーク内容、その他の個人情報を収集しません。

ブックマークデータ

拡張機能は Chrome の bookmarks API を使ってフォルダと保存済みリンクを読み取り、新しいタブのダッシュボードに表示します。このデータは Chrome 内でローカルに処理され、当方または第三者サーバーへ送信されません。

ローカル拡張機能設定

Bookmark Nav はテーマ、最後に選択したビュー、展開したフォルダなどの設定を Chrome のローカル拡張機能ストレージに保存する場合があります。これらは、Chrome の同期設定に従う場合を除き、端末上に残ります。

分析とトラッキング

Bookmark Nav は拡張機能内で Google Analytics などの分析トラッカーを使用しません。ブックマークの使い方を追跡しません。

Cookie

Bookmark Nav 拡張機能は Cookie を使用しません。この静的サイトの基本ページにも Cookie は不要です。

子どものプライバシー

Bookmark Nav は一般向けの生産性ツールであり、子どもの個人情報を意図的に収集しません。

ポリシーの変更

拡張機能の変更に応じて、このプライバシーポリシーを更新する場合があります。重要な変更がある場合は、ページ上部の発効日を更新します。
