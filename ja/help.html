Bookmark Nav ヘルプ

Bookmark Nav のインストール、ブックマーク権限、検索、Chrome の標準新しいタブへの戻し方を説明します。

はじめに

  • Chrome Web Store から Bookmark Nav をインストールします。
  • Chrome が求めたらブックマーク権限を許可します。
  • 新しいタブを開くとブックマークのダッシュボードが表示されます。
  • 検索欄に入力すると、タイトル、URL、フォルダパスで絞り込めます。

なぜブックマーク権限が必要ですか？

既存のフォルダと保存済みリンクを表示するために、Chrome の bookmarks API が必要です。Bookmark Nav はこのデータを Chrome 内でローカルに読み取り、アップロードしません。

検索のしくみ

検索はブックマークのタイトル、URL、フォルダパスに一致します。ページ名を忘れても、フォルダを覚えていれば探しやすくなります。

最近追加とすべてのブックマーク

最近追加は新しく保存したリンクを表示します。すべてのブックマークでは全フォルダを横断して検索できます。

Chrome の標準新しいタブに戻す

chrome://extensions を開き、Bookmark Nav を無効化または削除します。Chrome は標準の新しいタブに戻ります。

書き出したブックマークを結合

2 つの Chrome ブックマーク HTML を選び、重複をプレビューし、結合ファイルをダウンロードして Chrome にインポートします。書き出したファイルを結合するもので、アカウントや同期の統合ではありません。

ウェブ版と拡張機能の違い

ウェブ版は拡張機能なしで使え、HTML をダウンロードするだけです。直接追加、バックアップ、変更確認付きの取り消しは拡張機能 1.3.1 向けに準備済みですが、公開版に含まれるとは限りません。インストール済みバージョンと結合メニューを確認してください。直接追加は独立フォルダを作り、元の HTML の日付ではなく現在の日付を使います。
