Bookmark Nav 隐私政策

2026-10-09

摘要

Bookmark Nav 不收集、上传、出售、出租、转移或共享你的书签或个人信息。你的书签数据保留在浏览器中。

我们不收集的信息

Bookmark Nav 不需要账户，也不收集你的姓名、邮箱、浏览历史、按键、书签内容或其他个人信息。

书签数据

扩展使用 Chrome 书签 API 展示和搜索书签，并执行你选择的编辑、移动、删除和导入操作。数据仅在 Chrome 本地处理，不会发送给我们或第三方服务器。

本地扩展设置

主题、所选视图、展开的文件夹及本地使用计数保存在 Chrome 扩展本地存储中，不使用扩展同步存储。最近一次导入的状态、新文件夹 ID 与内容指纹也仅保存在本地，用于校验后撤销。导入 HTML 和书签内容不会保存在扩展存储中。

本地文件处理

网站与扩展合并工具仅在当前标签页内存中读取所选 HTML 文件，不上传、不用于分析；刷新或离开会清除文件。下载的 HTML 备份和报告保存在你的设备上。新增书签可能由 Chrome 按浏览器设置同步。扩展安装链接仅含固定推广标记，不包含文件名或书签网址。

分析和跟踪

Bookmark Nav 扩展内不使用 Google Analytics 或其他分析跟踪器。我们不会跟踪你如何使用书签。

Cookie

Bookmark Nav 扩展不使用 Cookie。这个静态网站的核心页面也不需要 Cookie。

儿童隐私

Bookmark Nav 是通用效率工具，不会有意收集儿童个人信息。

政策变更

当扩展功能变化时，我们可能更新本隐私政策。发生重大变更时，页面顶部的生效日期会同步更新。

联系方式

如有隐私政策相关问题，请发送邮件至 cameoshell09@gmail.com。

有限使用

Bookmark Nav 遵守 Chrome Web Store 用户数据政策及其有限使用要求。书签访问仅用于此处描述的面向用户的功能，不用于广告、用户画像、出售或无关的数据转移。 Chrome Web Store Limited Use

导入记录保留

后续导入会替换最近一次本地导入记录，卸载扩展会移除该记录。关闭工具会清除所选文件，但不一定会停止已在扩展后台启动的导入。
