Bookmark Nav 帮助

了解如何安装 Bookmark Nav、授权书签权限、快速搜索，以及恢复 Chrome 默认新标签页。

入门

  • 从 Chrome 网上应用店安装 Bookmark Nav。
  • 当 Chrome 请求时，同意书签权限。
  • 打开新标签页查看书签仪表盘。
  • 在搜索框输入内容，按标题、URL 或文件夹路径筛选。

为什么需要书签权限？

扩展需要 Chrome 书签 API 来显示你已有的文件夹和链接。Bookmark Nav 只在 Chrome 本地读取这些数据，不会上传。

搜索如何工作？

搜索会匹配书签标题、URL 和文件夹路径。即使记不清页面标题，只记得文件夹，也能更快定位。

最近添加和全部书签

最近添加显示最新保存的链接。全部书签提供跨所有文件夹的扁平搜索视图。

恢复 Chrome 默认新标签页

打开 chrome://extensions，找到 Bookmark Nav，然后停用或移除扩展。Chrome 会恢复默认新标签页。

合并书签文件

合并两份 Chrome 书签导出时，选择两个 HTML 文件，预览重复项，下载合并结果，再导入 Chrome。这是在合并导出文件，不是合并 Chrome 账号或同步库。

合并书签文件 · 阅读书签合并指南

网页版与扩展导入的区别

网页版无需安装扩展，只下载 HTML。直接追加、备份和校验后撤销已准备在扩展 1.3.1 中，不应假设当前商店版已经包含。请核对已安装版本及“导入与合并”入口。直接追加创建独立文件夹，使用当前日期，而非 HTML 原始日期。
